# 국내외 기술동향 조사 스킬

과제명을 확정하고, 이후 모든 조사가 공유할 **키워드 세트**를 만드는 첫 조사 단계.

## 워크플로우

### 1. 과제명 도출
`00_rfp_selected.md`의 목표·핵심요구를 반영해 과제명 후보 2~3개를 만들고, 대표 1개를 근거와 함께 선정한다.

### 2. 키워드 세트 추출 (후속 공유용)
과제명·RFP에서 3종을 뽑아 `10_project_title.md`에 별도 저장:
- **핵심기술어**(국문), **응용분야어**(국문), **영문 검색어**(글로벌 검색용), **주요기업 후보**
이 세트는 시장/정책/특허 조사가 그대로 재사용한다 → 조사 간 일관성의 핵심.

### 3. 국내외 조사 (병행)
- 글로벌: `WebSearch`로 영문 검색어 조회 — 최신 기술, 연구그룹, 상용화 사례.
- 국내: `NaverSearch-search_news`/`search_academic`/`search_webkr`로 국내 동향·연구기관.
- 각 기술 항목마다 (내용 + 출처 URL + 발행연도)를 기록.

### 4. 주요기업·핵심기술 정리
기업별로 (보유 핵심기술 · 기술 성숙도 · 대표 제품/사례)를 표로 정리한다.

## 출력
- `_workspace/10_project_title.md` — 확정 과제명 + 키워드 세트(**후속 필수 입력**)
- `_workspace/11_tech_trend.md` — 국내외 동향 + 기업/기술 표 + 출처
첫 줄: `## STATUS: OK`

## 원칙
- **출처 병기 필수.** 상충 정보는 삭제하지 말고 출처와 함께 병기한다.
- 결과가 빈약하면 키워드를 확장/치환해 최소 3변형 재검색한다. 근거 없는 일반론으로 채우지 않는다.
