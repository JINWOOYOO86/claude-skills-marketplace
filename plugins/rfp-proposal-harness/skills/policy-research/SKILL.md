# 정책조사 스킬

과제의 정책적 정당성을 뒷받침하는 근거와 인사이트를 만든다.

## 워크플로우

### 1. 입력 로드 & 검색어 변환
`_workspace/10_project_title.md`의 키워드를 **정책 검색어**로 변환한다(관련 부처명·국가계획명·법령명 결합).

### 2. 국가계획·부처정책 조사
`WebSearch` + `NaverSearch-search_news`로 조회:
- 관련 부처(과기정통부·산업부·중기부 등) 정책·예산 방향
- 국가 R&D 로드맵·기본계획·전략기술 지정 여부
- 관련 법·제도·규제
각 항목에 원문/보도자료 링크를 남긴다.

### 3. 10년 타임라인
과거~현재 정책 변화를 연대표로 정리하고, 향후 예고된 정책/예산 방향을 포함한다.

### 4. 인사이트 도출 (핵심)
단순 나열로 끝내지 말고 **"이 과제가 왜 지금 정책적으로 타당한가"**의 결론 문단을 만든다.
이것이 계획서의 "추진 필요성/정책 부합성"과 평가위원의 부합성 채점 근거가 된다.

## 출력
`_workspace/13_policy.md` — 정책 타임라인(10년) · 관련 계획/법제도 표 · 향후 방향 · **정책 인사이트 결론** · 출처.
첫 줄: `## STATUS: OK`

## 원칙
- **정책 원문 출처 필수.** 접근 불가 시 보도자료로 대체하되 출처 명시.
- 10년 데이터가 부족하면 확보 범위를 명시하고 진행. 없는 정책을 지어내지 않는다.
