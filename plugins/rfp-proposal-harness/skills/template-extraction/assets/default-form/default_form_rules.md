# 기본 양식 규칙표 (default_proposal_form.hwpx 추출본)

> 이 파일은 `template-extraction` 스킬이 **기본 양식으로 폴백할 때 그대로 복사해 쓰는** 사전 추출본이다.
> 공고 첨부 서식이 있으면 이 파일을 쓰지 말고 그 서식에서 새로 추출한다.

## 1. 제출 문서 목록

| 문서명 | 형식 | 필수여부 |
|---|---|---|
| 연구개발계획서 | HWPX | 필수 |

※ 요약서·예산서·별지 서식은 이 양식에 포함돼 있지 않다. 공고에서 요구하면 별도 확보 필요.

## 3. 서식 규칙 표

| 항목 | 값 | 출처 |
|---|---|---|
| 용지 | A4 세로 (`width=59528`, `height=84186` HWPUNIT) | `section0.xml` `hp:pagePr` |
| 여백 | 좌우 **8504**(30mm) / 위 **5668**(20mm) / 아래 **4252**(15mm) / 머리말·꼬리말 4252 | `section0.xml` `hp:margin` |
| 본문 글꼴·크기 | **함초롬돋움 11pt** (`charPr 6`) | 양식 안내문 "돋움 11pt" + `header.xml` |
| 표 안 글자 | **9pt** (`charPr 2·3·4`) | `header.xml` |
| 장 제목 | **16pt** (`charPr 5`) | `header.xml` |
| 기본값(미지정 문단) | 10pt (`charPr 0·1`) | `header.xml` |
| 줄간격 | **160%** (일부 문단 150%·130%) | `header.xml` `paraPr` |
| 사용 글꼴 | 함초롬돋움 / 함초롬바탕 (임베드 없음) | `header.xml` `hh:fontfaces` |
| **전체 분량** | **10 페이지 내외** (A4 / 돋움 11pt / 줄간격 160%, **표·그림 포함**) | 양식 안내문 |
| 섹션별 권장 분량 | 0.요약문 **1p** / 1.배경·필요성 **2p** / 2.목표 **2p** / 3.내용·수행방법 **3p** / 4.기대효과·활용 **2p** | 양식 안내문 |
| 양식 내 표 | 2개 (연차별 목표표, 추진일정 간트표) | `section0.xml` `hp:tbl` ×2 |

**스타일 매핑(HWPX 조립용)** — `analyze_template.py` 의 `confidence: estimated` 결과는 전 항목 charPr 0으로 뭉개지므로 아래 값으로 수동 교정할 것:
`본문 charPr6=11pt 함초롬돋움` / `표 charPr2=9pt` / `장제목 charPr5=16pt` / `캡션 charPr4`.
`build_hwpx.py` 는 자체 기본 여백(20mm)을 쓰므로 위 여백값으로 치환해야 한다.

## 4. 주의사항 체크리스트

- [ ] **분량 10p 내외** — 표·그림 포함 기준이다. 필수기재와 충돌하면 사용자에게 판단을 올린다(실측: RFP 필수내용을 다 담으면 20p를 넘는다).
- [ ] 기술분류는 **소분류 3순위까지 비중(%) 합 100**으로 기재.
- [ ] KPI는 **5개 내외, 가중치 합 100%**.
- [ ] 간트표는 **1차년도만** 기입하도록 양식이 지시한다.
- [ ] 연차별 서술은 내용·방법·근거 3요소를 모두 갖출 것(양식 명시 요구).
- [ ] 간트 채움 문자로 `■`(U+25A0)를 쓰면 표 셀에서 탈락한다 → **`◼`(U+25FC)** 사용.

## 5. 명시 없음 (추정 금지)

- 장평·자간, 각주 크기, 쪽번호 위치·형식
- 표·그림 캡션 번호 규칙
- 파일명 규칙, 제출 부수
- 별지·부속 서식 목록

이 항목들은 공고에 별도 지시가 있으면 그것을 따르고, 없으면 사용자 확인 후 결정한다.
