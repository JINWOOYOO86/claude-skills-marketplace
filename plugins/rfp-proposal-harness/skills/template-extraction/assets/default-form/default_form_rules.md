> ## ⛔ 이 절은 협상 대상이 아니다
>
> **분량 규정과 절 제목은 「지키면 좋은 것」이 아니라 「어기면 형식 축이 무너지는 것」이다.**
> 아래 두 규칙은 **작성 착수 전에 예산으로 확정**하고, 개정 라운드마다 재확인한다.
>
> **규칙 1 — 장별 분량 배분(0:1p / 1:2p / 2:2p / 3:3p / 4:2p = 10p)을 초과 설계하지 않는다.**
> 지시가 아무리 많아도 **먼저 배분 안에 들어갈 형태로 설계**한다. 다 쓰고 나서 줄이는 순서는 반드시 실패한다.
>
> **규칙 2 — 양식이 정한 장·절 제목은 한 글자도 바꾸지 않는다(§4 목차 트리).**
> 서술형 제목(예: "국내는 냉매를 만들지 못한다")으로 바꾸면 양식·목차 준수 항목에서 감점된다.
> 내용을 드러내고 싶으면 **제목은 원문 그대로 두고 절 첫 문장을 굵은 리드로** 쓴다.
> **절을 새로 만들지도 않는다** — 양식에 없는 내용(예: 위험관리)은 가장 가까운 절 안의 굵은 리드로 넣는다.

> ## ⛔ 규칙 3 — 양식의 **설명문은 쓰고 나서 지운다**
>
> 양식이 각 절에 달아 둔 안내 문구("연구의 한 줄 요약이 드러나도록 기재", "표 또는 그림으로 요약 권장" 등)는
> **집필 중에는 체크리스트로 쓰고, 산출물에는 한 줄도 남기지 않는다.**
> 절차는 세 단계로 고정돼 있다 — 어기면 `gate_form.py` F-5 가 잡는다.
>
> 1. `form_scaffold.py` 로 골격 생성 → 설명이 `<!--FORM-GUIDE …-->` 주석으로 들어간다
> 2. 주석을 보며 본문을 채운다 (이 파일이 개정 라운드 내내 원본이다)
> 3. 조립 직전 `form_strip.py` 로 주석을 **전량 제거**한 `*.build.md` 를 만들어 그것으로 빌드한다
>
> ⚠️ 예외 — **「가. 1차년도」·「[표 A]」처럼 양식이 본문에 그대로 쓰라고 준 표제**는 설명문이 아니다.
> 명세의 `residue_exempt` 에 등록돼 있으며 **지우면 오히려 양식 위반**이다.

> ## ⛔ 규칙 4 — 본문은 **개조식**으로 쓴다
>
> 국가 R&D 계획서의 표준 서술 방식이다. 규격은 명세의 `writing_style` 이며 `gate_form.py` **F-8** 이 검사한다.
>
> - **마크다운 중첩 목록**으로 쓴다 — kordoc 이 `- ` → **□**, `  - ` → **ㅇ** 로 조판한다(□·ㅇ 직접 타이핑 금지)
> - **명사형 종결**(~함/임/필요/전무/예정). `~이다 / ~한다 / ~했다 / ~합니다` 금지
> - **깊이 2단계**(□ 논점 → ㅇ 근거·수치·출처), 한 항목 **160자 이내**
>
> ★★ **개조식은 서술식보다 30% 넘게 길다**(실측 10p → 13p). **자수가 아니라 항목 수가 분량을 지배**하므로
> 줄일 때는 문장을 깎지 말고 **항목을 합쳐라.** 10p 기준 예산은 **산문 6,500~7,000자 · 항목 100개 내외**다.

**분량 산정의 실측 원단위** — 이 값으로 착수 전에 예산을 짜면 재작업이 없다.

> ★★ **2026-08-14 재측정 — 산문 원단위를 1,750자/p 에서 「약 1,000자/p」로 정정한다.**
> 이 양식의 서식(A4 · **좌우 여백 30mm** · 돋움 11pt · 줄간격 160%)에서 순수 산문 쪽을 PDF 로 실측하니
> **995 · 1,036 · 1,060자**였다. 종전 1,750자/p 는 여백이 좁은 다른 문서에서 나온 값이며,
> 그 값으로 예산을 짜면 **분량을 1.7배 과소평가**한다(실제로 「10p 예산」 원고가 14p로 나왔다).
> 검증: 산문 8,100자 + 표 5개 + 그림 1장 = **실측 10p**.

| 요소 | 소모 |
|---|---|
| 산문 | 약 **1,000자 / 페이지** (여백 30mm 기준 실측) |
| 표 (**3~4열**) | **1개당 0.4~0.6p** |
| 표 (**5~6열**) | **1개당 0.7~0.9p** |
| 표 (**7열 이상**) | ★ **1개당 1.0p 이상** — 열이 좁아져 셀 텍스트가 세로로 늘어난다 |
| 그림 | **1장당 0.5~1p** (실측 0.5p. 본문 높이의 30~35%만 차지해도 페이지 넘김이 생겨 1p 를 먹기도 한다) |

> ★★ **열 수가 분량을 지배한다 (2026-08-13 실측)**: 표 10개·셀 텍스트 **3,512자**뿐인 문서에서
> **표가 9.3p**를 먹었다(개당 0.93p). 같은 문서의 산문은 13,425자로 7.7p였다 —
> **표는 글자의 1/4로 페이지의 1.2배를 소모**했다. 원인은 8열 KPI표·13열 간트표다.
> 열을 5 이하로 재설계하자 **18p → 15p**로 3p가 회수됐다.
> **「표 1개당 0.4~0.6p」는 3~4열 기준이다. 7열 이상 표에 적용하면 예측이 2배 빗나간다.**

→ 10p 안에 넣으려면 **표 5~6개(간트 제외 전부 6열 이하) + 그림 1장 + 산문 약 8,000자**가 현실적인 상한이다.
표를 10개 넘게 쓰거나 7열 이상 표를 여러 개 쓰면 산문을 아무리 줄여도 12p 아래로 내려오지 않는다.

**실측 감축 사례(2026-08-14, AI냉매 계획서 14p → 10p)** — 효과가 큰 순서다.

| 조치 | 회수 |
|---|---|
| ① 8열 KPI표·6열 기관표 등 **넓은 표를 없애거나 서술로 이관** | 약 1.5p |
| ② 표 10개 → 5개(요약표·[표 A]·KPI·[표 B]·표지) | 약 1.0p |
| ③ 그림을 §3 머리에서 **§2-1 로 이동**(양식의 「표 또는 그림으로 요약 권장」도 함께 충족) | 0.5p + 배분 재조정 |
| ④ 산문 9,600자 → 8,100자 | 약 1.5p |

⚠️ **장별 배분은 「내용 총량」이 아니라 「쪽 경계」로 결정된다.** 한 장을 줄이면 다음 장의 시작 위치가
당겨져 **다른 장이 초과로 뒤집히는** 일이 흔하다(실측: 2장을 줄였더니 3장이 2.9p→3.3p로 표시).
그래서 **감축은 한 번에 끝내지 말고 `gate_pages.py` 로 매번 재측정**한다.

**착수 전 분량 예산표** — 작성 시작 전에 이 표를 채우고, 채워지지 않으면 쓰기 시작하지 않는다.

## 3. 서식 규칙

PDF가 규정하는 것은 **A4 / 돋움 11pt / 줄간격 160%** 세 가지뿐이다. 나머지는 명시가 없으므로 도구 기본값을 쓰되 값을 문서에 남긴다.

| 항목 | 값 | 근거 |
|---|---|---|
| 용지 | **A4 세로** (`width=59528`, `height=84186` HWPUNIT) | PDF 안내문 |
| 본문 | **돋움 11pt** | PDF 안내문 |
| 줄간격 | **160%** | PDF 안내문 |
| 여백 | 좌우 8504(30mm) / 위 5668(20mm) / 아래 4252(15mm) / 머리말·꼬리말 4252 | **명시 없음** — 도구 기본값을 명시적으로 고정 |
| 표 안 글자 | 9pt | 명시 없음 — 분량 관리상 관행 |
| 장 제목 / 절 제목 | 16pt / 13pt 굵게 | 명시 없음 — 위계 확보용 |

### 조립 절차 — kordoc 프리셋 + 헤더 패치

조립은 **kordoc**(npm, MIT — `npx` 실행이라 설치가 없다)의 계획서 프리셋으로 한다.
**명령 전문과 원고 전처리는 `hwpx-writing` 스킬 §3에 있다.** 여기서는 서식 패치만 다룬다.

```bash
npx -y kordoc@^4 generate 30_proposal.build.md -o 30_raw.hwpx \
  --preset 계획서 --font gothic --pt 11 --line-spacing 160 --paper A4 \
  --h2-marker none --fonts "body=돋움,heading=돋움,table=돋움" --image-dir 20_figures
```
⚠️ 입력은 **설명문을 제거한 `*.build.md`**(§2 규칙 3)이고, `--h2-marker none` 이 없으면
장 제목의 번호가 `□` 로 치환돼 목차 준수가 깨진다.

프리셋 기본값은 **양식값과 다르다**(실측: 여백 좌우 5669=20mm, 글꼴 5종 혼용). 산출물에 다음을 패치한다.

```python
# ① 여백을 양식값으로 고정 — Contents/section*.xml
s = re.sub(r'<hp:margin[^>]*/>',
           '<hp:margin header="4252" footer="4252" gutter="0" '
           'left="8504" right="8504" top="5668" bottom="4252"/>', s)
# ② 글꼴을 "돋움"으로 통일 — Contents/header.xml
for face in ['함초롬바탕','함초롬돋움','한양신명조','한양중고딕','HY견고딕']:
    h = h.replace(f'face="{face}"', 'face="돋움"')
```

⚠️ zip 재작성 시 `mimetype` 은 **ZIP_STORED** 로 보존한다(안 하면 열리지 않는다).
목표 서식값은 동봉 `default_form_style.json`(본문 11pt / 표 9pt / 장제목 16pt 검정 / 절제목 13pt 굵게).

### ⚠️ 함정 4개 (전부 실측)

**⑴ `charPr 5`(장 제목 16pt)는 색이 `#2E74B5` 파랑이다.** Word Heading 1 색이 템플릿에 남은 것으로, 그대로 쓰면 장 제목이 파랗게 인쇄된다. 배포처 양식 본문이 실제로 쓰던 색도 `#000000` 하나뿐이었다 → **검정으로 교정**.

**⑵ 절 제목용 크기가 템플릿에 없다.** 신설하지 않으면 `1-1.` 등이 본문과 같은 11pt로 나가 위계가 사라진다 → `charPr 7`(13pt 굵게).

**⑶ "돋움"은 `돋움` 이지 `함초롬돋움` 이 아니다.** 템플릿 정의는 함초롬돋움이라 그대로 두면 안내문과 다른 글꼴이 된다.
⚠️ **글꼴 교체는 분량을 바꾼다** — 실측으로 **함초롬돋움 11p → 돋움 12p**(같은 원고, +1p)였다. 돋움이 더 넓다. **글꼴을 확정한 뒤에 분량을 맞출 것.** 반대로 하면 분량 작업을 두 번 한다.

**⑷ `charPrIDRef="0"` 이 표마다 1건씩 보이는 것은 누수가 아니다.** `<hp:tbl>` 을 **감싸는 run** 의 속성이라 인쇄되는 글자가 없고, 실제 셀은 전부 `charPr 2`(9pt)다. 표 안을 정규식으로 치환하려 들지 말 것 — 텍스트 추출 정규식이 표 첫 셀 문자열을 이 run 소속으로 잘못 묶어 보여준다.

## 5. ★ 양식이 지정한 표 2개 — 형식을 바꾸지 말 것

PDF **2~3쪽**에 실물이 있고 `default_proposal_form.md` 에 전사돼 있다. 둘 다 채워 넣어야 하는 지정 서식이다.

**[표 A] 단계별·연차별 목표** (2-2) — 열은 `구분 / 연차 / 목표` 3개, 행은 `1단계 1차년도`·`1단계 2차년도`·`…`·`N단계 N차년도(최종)`.

**[표 B] 추진 일정(간트)** (3-3) — 열은 `추진 내용` + **월 1~12 = 13열**, **1차년도만 기입**한다.
- 첫 행 예시가 `계획 수립·자료조사`에 1·2월 `■` 표기다.
- ⚠️ **분기(4Q) 단위로 4개 연차를 한 표에 넣는 것은 양식 위반**이다. 2~4차년도는 표가 아니라 서술로 덧붙인다.
- 채움 문자 `■`(U+25A0)는 kordoc 조립에서 표 셀·본문 모두 **보존**됨을 실측 확인했다(2026-08-13). 양식 원본대로 쓰면 된다.

## 5-2. 기계판독 명세 — `default_form_spec.json`

이 문서의 규칙 중 **기계로 검사 가능한 부분**은 같은 폴더의 `default_form_spec.json` 에 들어 있다
(장·절 제목, 절별 요구 항목과 정규식 프로브, 지정 서식, 쪽 배분, 상한, 설명문 잔존 패턴).
`form_scaffold.py`·`form_strip.py`·`gate_form.py`·`gate_pages.py` 가 **모두 이 파일 하나를 읽는다.**
공고 지정 서식이 있으면 `template-extraction` 이 같은 스키마로 `01_template_spec.json` 을 만들어 대체한다.
