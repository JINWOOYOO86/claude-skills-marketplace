# 특허조사 스킬

과제 관련 특허를 조사하고 기술 성숙 단계를 판정한다.

## 워크플로우

### 1. 입력 로드
`_workspace/10_project_title.md`(키워드) + `_workspace/12_market.md`(주요기업). 시장조사가 없으면 키워드만으로 진행하고 기업 축은 생략 표시.

### 2. 특허 검색
`WebSearch`로 공개 특허 소스 조회: Google Patents, 특허청 KIPRIS 공개정보, USPTO, 특허 보도자료.
- 키워드 검색 + 주요기업 출원인 검색을 병행.
- 각 특허의 (출원인 · 출원/공개번호 · 출원연도 · 핵심 청구 요지)를 수집.

### 3. 상위 5건 심층분석
과제 관련성이 높은 5건을 선정해 표로:
(출원인 · 번호 · 출원연도 · 핵심기술 · **과제와의 연관성 / 회피·활용 포인트**)

### 4. 통계 → 수명주기 판정
연도별 출원 건수 추이를 근거로 **초기 / 성장기 / 성숙기 / 쇠퇴기** 중 하나로 판정하고 근거를 명시.
- 출원 급증 = 성장기, 정체·감소 = 성숙/쇠퇴 등 추이 논리를 함께 적는다.

## 출력
`_workspace/14_patent.md` — 연도별 통계 + 수명주기 판정 · 상위 5건 표 · 출원인 분포 · 출처.
첫 줄: `## STATUS: OK`

## 원칙 (정확성 최우선)
- **특허번호·출원인은 절대 추정·생성 금지.** 확인 불가하면 "미확인"으로 표시한다. 허위 특허번호는 계획서 신뢰도를 무너뜨린다.
- 공개 DB 표본이 제한적이면 표본 한계를 명시하고 정성 판정한다.
