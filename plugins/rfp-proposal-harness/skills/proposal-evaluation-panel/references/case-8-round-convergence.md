## 4. 대표 사고 5선

**⑴ 부분문자열 오염** — 구값을 고치려 한 `"8배"→"31배"` **전역 치환**이 무관한 `4.8배`·`2.8배`를
`4.31배`·`2.31배`로 파괴했다. 해당 축 점수가 **처음으로 하락**했다. → 규율 A

**⑵ 검증 없는 완료 보고** — 치환이 조용히 실패했는데 개정이력에 "정정 완료"로 기재 →
위원이 **"개정이력과 본문 불일치"**로 적발. → 규율 B

**⑶ 검사를 통과하도록 고치기** — 존재하지 않는 절 `§1-4`를 **존재하지만 무관한** `§1-1`로 바꿔
`grep §1-4 = 0건`을 통과시키고 의미 오류를 존치했다. 위원장이 *"검사를 통과하도록 고치는 것과
옳게 고치는 것이 갈라진 첫 사례이며 하네스 차원에서 가장 심각한 신호"*로 판정. → 규율 F

**⑷ 위원장의 물량 추정 오류** — "4개소에서 6,600~8,900자가 나온다"는 판정 위에 두 라운드의
최대 과제가 세워졌으나, 전수 조사 회수량은 **1,690자**(적중률 19~26%)였다. 위원장이 R8에서
**절차 위반으로 규정하고 해당 지시를 무효 선언**했다. → 규율 K

**⑸ 【A】 임의 탈락** — 위원장이 【A】 12건 중 4건만 지시하고 8건을 근거 없이 탈락시켰다.
근거 축은 그 8건 때문에 −4.5에 묶여 있었고, **11건 전량을 이관하자 94.0 → 100.0**이 됐다. → 규율 L

## 5. ★ 가장 비쌌던 교훈 — 달성 불가능한 종료 조건

「6축 전원 95」는 **처음부터 불가능**했다. 형식 축의 회수 불가 감점이
**분량 −6.65 + 기관 실명(재현 문서) −1.50 = 천장 91.85**였기 때문이다.
이를 **7라운드째에야** 발견했다.

- **R1에서 축별 천장을 계산했다면 R2에 알 수 있었다** → Phase 0.5(종료 조건 도달 가능성 사전 점검) 신설.
- 부수 사고: 「20p로 압축」 지시를 3개 라운드가 추격했으나, 구성비 실측 결과
  **산문 본문을 전부 삭제해도 표·표주석·각주만으로 15.5p**가 남아 애초에 불가능했다
  (문서 구성: 표 27.6% / 산문 48.2% / 주석·각주 22.7%).
- 최종 대체 조건(사용자 승인): ①형식 제외 5축 ≥95 ②형식은 「분량 제외 소계」 ≥95
  ③【A】 잔여 0 ④규율 H·I·J 전항 통과.

## 6. 건전성 신호로 판정된 것들

- **위원 2인의 자기 지시 철회** — 한 위원이 자기가 요구했던 표준 병기 지시를 조사파일 실측을 근거로
  철회했다. 그 철회가 없었다면 **적용제외 대상 표준을 근거로 든 오류**가 원고에 들어갔을 것이다.
  다른 위원은 자기 과대감점 2건을 정정하며 종전 척도 적용값도 병기했다. → 규율 M
- **100점을 내면서 "검사를 축소하지 않았음"을 명시** — 근거 위원이 배점표를 **미리 공시**한 뒤
  실측을 대입해 산출했음을 판정문에 남겼다.
- **위원장이 자기 판정문의 자기모순을 공개** — 조건 판정에서 자기에게 불리한 반사실
  (「이 항목을 【A】로 세면 REVISE」)을 그대로 노출했다.
- **자기 측정 한계의 자진 노출** — 형식 위원이 PageCount를 「PASS」로 위장하지 않고
  "COM 보고값 수용"으로 표기했다. → 규율 J-6

## 7. 재현 문서의 경계

**내용상 제출 가능 / 서류상 불가.** 컨소시엄 실체·수요기업확약서 부재가 형식 탈락 사유다.
실제 신청 시 자동 소멸하는 감점 약 −5.0과, 반드시 채워야 하는 항목은 분리해서 관리할 것.
→ Phase 0.3(재현 문서 모드 선언)이 이 구분을 라운드마다 재발견하지 않게 한다.
