# 근거·정합성 검증 스킬

공통 루브릭: `../proposal-evaluation-panel/references/rnd-evaluation-rubric.md`. **신뢰도 게이트** — 이 축이 REVISE면 위원장은 통과시키지 않는다.

## 검증 절차 (100점=무결점, 결함마다 감점)
1. **수치 추적** — 본문의 모든 정량 주장(시장규모·성능·매출·CAGR)을 `12_market.md`/`11_tech_trend.md`/`14_patent.md`와 1:1 대조. 출처 없음·불일치 → 치명 감점.
2. **특허 진위** — 본문 특허번호·출원인이 `14_patent.md`에 실재하는가? **지어낸 특허번호는 즉시 치명(-20~-30)**.
3. **문서 내 교차 비교** — 정량목표표 ↔ 요약 ↔ 기대효과의 동일 수치가 일치하는가? 자기모순 탐지.
4. **논리 일관성** — 필요성→목표→내용→기대효과 인과 사슬에 비약/순환이 없는가?
5. **과장·모호 적발** — "세계최초/획기적" 등 근거 없는 수식, 검증 불가 주장.

## 원칙 (반증 우선)
- 확인 불가한 주장은 "근거 있음"이 아니라 **"미검증"으로 감점**한다.
- 핵심 수치는 필요 시 `WebSearch`로 직접 교차확인한다.
- 근거 결함은 계획서 신뢰도를 무너뜨리므로 가장 엄격하게 본다.

## 출력
`_workspace/44_review_evidence.md`. 첫 줄: `## SCORE: NN/100  STATUS: PASS|REVISE`
- 미검증/불일치/과장 목록(본문위치 · 근거파일 대조결과 · 조치지시) · 자기모순 목록 · Gap-to-95.

## Gap-to-95 예시
"시장규모 XX억달러 주장에 12_market.md 출처 각주 추가", "본문 특허 KRxxxx는 14_patent.md에 없음 → 삭제 또는 실재 특허로 교체", "요약의 절감률 20%와 2장 목표치 15% 불일치 → 통일".

## ★ 공통 규율 (평가위원단 공통 — `proposal-evaluation-panel` 참조)

- **J-6 「측정 매체」 필수** — 모든 체크 항목에 **측정 매체**(md / hwpx / hwpx원시 / svg / 조사파일 / COM)를
  명시한다. **md 단독 측정 항목에는 「통과」를 발급할 수 없다** → 「미검증」으로 표기하고,
  판정문에 **「본 위원이 직접 측정할 수 없는 항목」 절**을 두어 위원장에게 고지한다.
  > 실측: 「평가방법 8행 존재」가 md에서는 참, 산출물에서는 거짓이었다(표가 hp:tbl 2개로 분할).
  > 「존재는 있고 구조가 깨진」 결함 3건이 **전부 존재 검사를 통과**했다.
- **배점 회수표 사전 공시** — 「이 항목 이행 시 +N.N」을 판정문에 미리 적는다. 다음 라운드 점수가
  **목표가 아니라 산출값**이 되어 사후 정당화를 막는다.
- **【A】/【B】/【C】 분류 필수** — 【A】 조사 불요 문서 내부 편집 / 【B】 추가 조사 필요 /
  【C】 실제 신청 시 확정. 위원장은 규율 L에 따라 **【A】를 취사선택하지 않는다.**
- **규율 M(지시 철회)** — 자기 지시를 철회·정정할 때는 ⑴1차 출처 근거 ⑵철회 사실과 사유를 판정문에 명시
  ⑶같은 라운드에 자기에게 불리한 검사도 수행. 점수를 올리는 철회는 위원장이 재검토한다.
  > 실측: 한 위원의 표준 병기 지시 철회가 없었다면 **적용제외 대상 표준을 근거로 든 오류**가 원고에 들어갔을 것이다.
- **회귀 전수 재검사(규율 H)** — 직전 라운드에 자기가 「완전 해소 확정」한 항목을 **매 라운드 전수 재검사**한다.
  개정은 반드시 신규 결함을 낳는다(실측 주입량: 한 라운드 최대 21.15점).
- **재현 문서 모드** — 재현·연습 과제로 선언된 경우, 기관 실명·기업 실적·확약서·양산 캐파 관련 감점은
  **상수로 계상**하고 매 라운드 재발견하지 않는다.
