# md → HWPX 변환 함정 (전부 실측)

> 출처: 어느 연구개발계획서 한 편을 8라운드에 걸쳐 개정하며 겪은 것들(2026-08). 모든 항목이 **실제 사고**이며,
> 대부분 **평가위원이 산출물에서 적발한 뒤에야** 원인이 밝혀졌다.

## 1. ★ 「존재는 있고 구조가 깨진」 결함 계보 — 3건 전부 존재 검사를 통과했다

| # | 사고 | 존재 검사 결과 | 실제 산출물 |
|---|---|---|---|
| 1 | 참고문헌 20건 | "20건 존재" **통과** | HWPX에서 **단일 문단 2,018자**로 병합 |
| 2 | 표주석 [주a]~[주j] | "10종 존재" **통과** | **단일 문단 1,407자**로 병합 |
| 3 | 평가방법 #8행 | "8행 존재" **통과** | 표가 `hp:tbl` **2개로 분할**, #8행이 **머리글 없는 고아 표**. **2개 판에 승계**된 뒤 평가위원 **3인이 독립 적발** |

**⇒ 존재 검사 단독은 거짓 통과를 발급한다.** 반드시 `scripts/gate_hwpx.py`(규율 J)로 **산출물 구조**를 검사할 것.

## 2. 마크다운 소스 함정

| 함정 | 증상 | 대응 |
|---|---|---|
| **표 중간의 빈 줄 1개** | 표가 `hp:tbl` 2개로 쪼개지고 뒤쪽이 `rowCnt=1` 고아 표가 된다. 페이지 경계가 사이에 오면 고아 행으로 인쇄 | 표 블록에 빈 줄 금지. `gate_hwpx.py` J-2(표 개수 선언 대조)·J-3(고아 표 0)로 검출 |
| **각주·주석의 연속 줄** | 빈 줄 없이 연속 배치하면 **한 문단으로 병합** | 항목 사이에 빈 줄 필수. J-5·H-5로 검출 |
| **`&` 직접 사용** | 이중 이스케이프되어 `&amp;amp;` 로 인쇄 | 소스에서 제거. 회귀 검사는 **`&amp;amp;`·`&amp;lt;`·`&amp;gt;` 3패턴 전부** (1패턴만 보면 놓친다) |
| **`<br>`·백틱·`<sup>`** | 변환되지 않고 그대로 인쇄 | 사전 제거 |
| **부등호 `>` `<`** | 태그로 오인 | **전각 `＞ ＜`** 사용 |
| **표 셀의 `\|`** | 표 구조를 깨뜨림 (MAPE 절댓값 기호에서 발생) | 「절댓값」으로 풀어쓰기 |
| **이미지 alt의 대괄호** | `IMAGE_MD_RE` 정규식이 깨짐 | 캡션은 **이미지 다음 줄에 별도 문단**으로 |
| **`■`** | **표 셀에서만 소리 없이 사라진다** (`xml_writer.py`가 무조건 제거). 간트차트가 빈 표로 인쇄 | **`◼`(U+25FC)** 사용. `LEVEL_MARKERS = ["■","□","●","○","▪","▫","∙","∘"]` 전부 회피 |
| **`⚠️`(U+26A0+FE0F)** | 두부(豆腐) 인쇄 위험 | 텍스트 `[유의]`로 치환 |

## 3. 빌드 파이프라인 함정

| 함정 | 대응 |
|---|---|
| **`analyze_template.py`의 `confidence: estimated` 스타일맵** | 전 항목이 charPr 0으로 뭉개져 본문이 10pt 함초롬바탕으로 나간다(양식 위반). `font_sizes` 맵을 보고 수동 교정한 `style.json`을 쓸 것 |
| **`build_hwpx.py`의 자체 기본 여백(20mm)** | 양식값으로 치환 필수. 예: 좌우 30mm = `8504` |
| **`section0.xml`의 XML 선언 누락** | 8개 파트 중 **이것만** 선언이 없었다. 빌드 후 `<?xml version="1.0" encoding="UTF-8" standalone="yes" ?>` 삽입. J-8로 검출 |
| **zip 재작성 시 `mimetype` 압축** | `mimetype`은 **ZIP_STORED**여야 한다. 재작성할 때 `ZipInfo.compress_type`을 원본에서 보존할 것 (안 하면 validate INVALID) |
| **`page_guard.py`** | 빈 양식→신규 생성 시 **구조상 항상 FAIL**. 게이트로 쓰지 말 것 |
| **`validate.py --strict`** | ZIP-surgery 전용. 신규 생성물은 FAIL하지만 한글 열림엔 무관 |
| **그림 축소** | `hp:pic` **블록 내부의 `hp:sz`만** 스케일할 것. 전역 치환하면 표까지 줄어든다. `hp:sz`는 `width`와 `height` 사이에 `widthRelTo="ABSOLUTE"`가 끼어 있어 단순 정규식이 0건 매칭 → `curSz`·`sz`·`scaMatrix`·`center`를 함께 처리 |

## 4. ★ 검사 스크립트 자체의 함정

| 함정 | 증상 | 대응 |
|---|---|---|
| **`.//hp:t` 로 문단 자수 계산** | **표 셀 텍스트가 표를 품은 문단에 합산**되어 거짓 FAIL. 실측: 818문단·최장 1,264자·1,000자 초과 **2건** → 표 내부 제외 시 154문단·최장 880자·초과 **0건** | `hp:p` 를 훑되 **하위 `hp:tbl` 을 만나면 내려가지 않는다**. `gate_hwpx.py`의 `local_text()` 참조 |
| **`hp:t` 런 단순 연결** | 런 사이에 구분자가 없어 `§3-3` + `45개월` 이 **`§3-345`** 로 붙어 거짓 깨진참조 | 문단·셀 단위로 모아 개행으로 이을 것 |
| **§ 참조 정규식** | 미국 CFR 인용 `40 CFR §84.54(a)(10)` 이 자기 문서 절 참조로 오인 | `§숫자.숫자` 는 외부 법령 인용으로 제외 |
| **BinData 해시로 소스↔산출물 대조** | 파이프라인 재인코딩으로 **해시가 원본과 다르다**(실측 430,678 → 391,806 B) | 해시는 **판 간 동일성 검사 전용**. 소스 정합은 SVG 문자열·기하 표본 대조로 |
| **토큰 수준 회귀 검사** | 「수치는 살아 있고 설명 문장만 사라진」 회귀를 못 잡는다(실측: `2차년도 39.0억은…` 삭제됐으나 `39.0` 이 격자에 존치해 PASS) | **문장·구문**을 `--resolved` 목록에 올릴 것 |

## 5. 쪽수·열림 검증

**한컴 COM이 정답**이다 — `HWPFrame.HwpObject` → `Open(..., "forceopen:true")` → `PageCount`.
WSL에서는 `powershell.exe -File <ps1>`, 파일은 **Windows 경로**에 둘 것. Open 성공 = 한글 열림 검증 동시 달성.

```powershell
$hwp = New-Object -ComObject HWPFrame.HwpObject
$hwp.RegisterModule("FilePathCheckDLL","FilePathCheckerModule")
$null = $hwp.Open("C:\...\chk.hwpx","","forceopen:true")
Write-Output ("PAGECOUNT=" + $hwp.PageCount)
$hwp.Clear(1); $hwp.Quit()
```

⚠️ **PageCount는 평가위원이 직접 측정할 수 없는 유일한 항목**이면서 형식 축 감점의 **80.6%**를 차지한다.
규율 J-6에 따라 위원은 이를 「PASS」로 위장하지 말고 **"COM 보고값 수용"**으로 표기해야 한다.

## 6. 기타 환경

- **WSL에서 Windows·클라우드 동기화 폴더를 편집할 때 간헐 EACCES** → python 직접 쓰기로 우회.
- **HWP(구형 바이너리) 읽기**: WSL에 hwp5txt·LibreOffice가 없으면 `olefile`+`zlib(-15)`+레코드 파싱
  (`tag=h&0x3FF`, `size=(h>>20)&0xFFF`, `HWPTAG_PARA_TEXT=67`, UTF-16LE) 자체 파서가 유일 경로.
- **선행조건**: `pip install --user --break-system-packages lxml olefile pillow`
  (WSL python3는 PEP 668이라 `--break-system-packages` 필수, venv는 ensurepip 부재로 실패)
