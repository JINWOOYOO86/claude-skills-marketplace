# 평가위원 채점 스킬 (5축 공용)

**호출 시 축 하나를 지정받는다.** §2에서 그 축의 규격만 적용하고, §1·§3은 전 축 공통이다.
공통 루브릭(채점 원칙·감점 앵커·95+ 조건): `../proposal-evaluation-panel/references/rnd-evaluation-rubric.md`

## §1. 공통 절차 (전 축 동일)

1. 축의 **읽을 곳**과 **대조 근거파일**(§2)을 연다. 근거파일이 없으면 채점하지 말고 **차단 보고**한다.
2. **100점에서 시작해 감점식**으로 내린다. 감점마다 (사유 · 본문 위치 · 감점폭)을 남긴다.
3. **적대적으로** 본다 — 후한 점수 금지, 근거 없는 주장은 「있음」이 아니라 「미검증」.
4. **직접 수정하지 않는다.** 고칠 일은 지시로만 남긴다.
5. 95 미만이면 **Gap-to-95 체크리스트** — 섹션 단위 실행지시로 쓴다("2-1 정량목표표에 평가환경 열 추가"처럼 어디에 무엇을).

**출력 첫 줄 고정**: `## SCORE: NN/100  STATUS: PASS|REVISE`
이어서 항목별 점수·감점내역 · 강점 · 결함(치명/중대/경미) · Gap-to-95 체크리스트.

### 축 D — 근거·정합성 ★ 신뢰도 게이트
**이 축이 REVISE면 다른 점수와 무관하게 위원장은 통과시키지 않는다.**
배점표 대신 **검증 절차**로 채점한다(100=무결점, 결함마다 감점).

1. **수치 추적** — 본문의 모든 정량 주장(시장규모·성능·매출·CAGR)을 `12_market.md`/`11_tech_trend.md`/`14_patent.md`와 1:1 대조. 출처 없음·불일치는 치명.
2. **특허 진위** — 본문 특허번호·출원인이 `14_patent.md`에 실재하는가? **지어낸 특허번호는 즉시 치명(−20~−30)**.
3. **문서 내 교차 비교** — 정량목표표 ↔ 요약 ↔ 기대효과의 동일 수치 일치 여부. 자기모순 탐지.
4. **논리 일관성** — 필요성→목표→내용→기대효과 인과 사슬의 비약·순환.
5. **과장·모호 적발** — "세계최초/획기적" 등 근거 없는 수식, 검증 불가 주장.

- **반증 우선**: 확인 불가한 주장은 「근거 있음」이 아니라 **「미검증」으로 감점**한다. 핵심 수치는 `WebSearch`로 직접 교차확인한다.
- Gap-to-95 예: "시장규모 주장에 `12_market.md` 출처 각주 추가", "본문 특허 KRxxxx는 `14_patent.md`에 없음 → 삭제 또는 교체", "요약 20% vs 2장 15% 불일치 → 통일".

## §3. 공통 규율 (전 축 필수)

- **J-6 「측정 매체」 필수** — 모든 체크 항목에 **측정 매체**(md / hwpx / hwpx원시 / svg / 조사파일 / COM)를
  명시한다. **md 단독 측정 항목에는 「통과」를 발급할 수 없다** → 「미검증」으로 표기하고,
  판정문에 **「본 위원이 직접 측정할 수 없는 항목」 절**을 두어 위원장에게 고지한다.
  > 실측: 「평가방법 8행 존재」가 md에서는 참, 산출물에서는 거짓이었다(표가 hp:tbl 2개로 분할).
  > 「존재는 있고 구조가 깨진」 결함 3건이 **전부 존재 검사를 통과**했다.
- **배점 회수표 사전 공시** — 「이 항목 이행 시 +N.N」을 판정문에 미리 적는다. 다음 라운드 점수가
  **목표가 아니라 산출값**이 되어 사후 정당화를 막는다.
- **【A】/【B】/【C】 분류 필수** — 【A】 조사 불요 문서 내부 편집 / 【B】 추가 조사 필요 /
  【C】 실제 신청 시 확정. 위원장은 규율 L에 따라 **【A】를 취사선택하지 않는다.**
- **규율 M(지시 철회)** — 자기 지시를 철회·정정할 때는 ⑴1차 출처 근거 ⑵철회 사실과 사유를 판정문에 명시
  ⑶같은 라운드에 자기에게 불리한 검사도 수행. 점수를 올리는 철회는 위원장이 재검토한다.
  > 실측: 한 위원의 표준 병기 지시 철회가 없었다면 **적용제외 대상 표준을 근거로 든 오류**가 원고에 들어갔을 것이다.
- **회귀 전수 재검사(규율 H)** — 직전 라운드에 자기가 「완전 해소 확정」한 항목을 **매 라운드 전수 재검사**한다.
  개정은 반드시 신규 결함을 낳는다(실측 주입량: 한 라운드 최대 21.15점).
- **재현 문서 모드** — 재현·연습 과제로 선언된 경우, 기관 실명·기업 실적·확약서·양산 캐파 관련 감점은
  **상수로 계상**하고 매 라운드 재발견하지 않는다.
  ⚠️ **상수의 크기는 위원이 각자 정하지 않는다.** R1 종료 시 **위원장이 축별 상수값을 확정해 판정문에
  고시**하고, 이후 전 위원·전 라운드가 **그 값을 그대로** 쓴다. 위원이 임의로 잡으면 같은 문서가
  라운드마다·위원마다 다른 점수를 받아 **수렴 판단 자체가 무너진다**(실측: 같은 항목을 두 위원이
  −1.0과 −2.0으로 각각 계상). 상수를 바꿔야 한다고 판단되면 값을 고치지 말고 **위원장에게 상신**한다.

## §4. 축 E 전용 — 회수 불가 감점의 분리 지표 (D-1 ~ D-3)

분량 초과처럼 **문서 외부 요인으로 회수가 불가능한 감점**이 형식 축을 게이트 아래로 묶으면,
「분량 제외 소계」 같은 **분리 지표**를 위원장에게 상신할 수 있다. 산정은 아래를 반드시 따른다.

- **D-1 분리 대상의 정의** — 분리하는 감점을 **항목 단위로 열거**한다. 「총 분량 페이지 초과」처럼
  **단일 항목**이어야 하며 뭉뚱그리지 않는다. 분량과 무관한 회수 불가 항목(기관 실명 등)은
  **소계에도 그대로 감점된 채 남긴다.**
- **D-2 환원식이지 면제식이 아니다** — 소계 = 총점 + 분리 항목 감점. **그 감점만 되돌린 값**임을
  명시한다. 축 전체 면제는 절대 제안하지 않는다(안전·자격요건까지 무심사가 된다).
- **D-3 이중 경로 교차검산 필수** — ⓐ `총점 + 분리감점` 과 ⓑ `100 − (분리 대상 외 감점 합)` 을
  **둘 다 계산해 일치**시킨다. 불일치하면 감점 분류가 틀린 것이다.

> 실측: 총점 91.75 → 소계 98.40. ⓐ 91.75 + 6.65 = 98.40, ⓑ 100 − (0.10 + 1.50) = 98.40 일치.
> 이 지표가 종료 조건 ②로 채택됐다.

**측정할 수 없는 항목의 표기** — PageCount는 이 축이 직접 측정할 수 없는 유일한 항목이면서
형식 축 감점의 **80.6%**를 차지한다. J-6에 따라 「PASS」로 위장하지 말고
**"COM 보고값 수용 + hwpx 자수 정합 확인"**으로 표기하고 판정문에 별도 절로 고지한다.
