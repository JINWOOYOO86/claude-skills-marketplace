아래 두 연구계획서(문서 A, 문서 B)는 같은 과제를 다룬다. 심사위원 입장에서 6개 항목마다 어느 문서가 나은지 판정하라.

규칙
- 본문 텍스트만 전달했다. 글꼴·줄간격·표 선 같은 서식은 판단하지 않는다.
- 두 문서를 누가 썼는지, 어느 쪽이 먼저 쓰였는지 추측하지 않는다. 문서 순서는 판정과 무관하다.
- 항목마다 반드시 A, B, 동등 중 하나를 고르고, 이유에는 근거가 된 문장을 짧게 인용한다.
- 답은 아래 표 하나만 쓴다. 표 앞뒤에 다른 글을 쓰지 않는다.

항목 정의
- 양식: 양식이 요구한 항목·표·캡션·번호·단위 표기가 빠짐없고 문서 전체에서 한 가지로 일관적인가
- 논리: 문제 → 기존 한계 → 연구내용 → 목표 → 성과지표가 이어지고, 서로 모순되는 서술이 없는가
- 구체: 목표 수치마다 단위·측정 조건·측정 방법·수행 주체가 있고, 실행 조건(장비·데이터 규모·판정 기준)을 제3자가 따라 할 수 있는가
- 간결: 같은 주장이 반복되지 않고, 절 첫 문장에 결론이 있으며, 한 문단이 한 주장만 하는가
- 문체: 용어·종결이 통일되고, 어색한 문장·과도한 압축·작성 메모나 작성 지시 문구가 없는가
- 구조: 목차만 읽어도 목표 → 내용 → 방법 → 성과 → 활용 흐름이 보이고, 절 사이가 이어지는가
