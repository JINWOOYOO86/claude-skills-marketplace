# 문장 구성 예시 (plan_v2 5단계 16, 2026-09-28)

**내용이 아니라 문장 구성의 기준이다.** 사람이 다듬어 블라인드 비교에서 이긴 제출본에서 고른 문장을
고유명사·수치·대상을 〔 〕로 가린 틀이다. 〔 〕 자리에는 이 절의 설계서·근거 값을 넣고, 가리지 않은 말도
그대로 옮기지 말고 내 문장으로 쓴다(원본과 8어절 이상 같으면 S-m7 floor 실패).

공통: 첫머리에 결론(주어와 판단)을 두고 「라벨: 내용」으로 시작하지 않는다. 한 항목은 한 주장, 종결은 「~함」「~임」.
절 번호로 다른 절을 가리키지 않고 그 내용을 직접 쓴다.

## 문제 정의

- 〔앞 단계 산출〕을 〔뒤 단계 검증〕과 연계하지 못해 〔외부 시점〕 전에 도입할 〔대상〕이 없음
- 〔판정 대상〕 확정이 〔수단〕에 의존하므로 〔수단〕 과정을 과제에 포함해 단절을 해소함

## 범위 한정

- 범위는 〔포함 작업 나열〕이며 〔제외 대상 나열〕은 제외함

## 한계와 대응 (차별성)

- 최근접 〔선행 권리·연구〕는 〔그 방식〕을 청구함 / 〔조건〕을 쓰는 〔대상〕으로 후보군을 한정해 해당 청구범위를 회피함
- 〔단계〕 사례가 없어 〔단계 나열〕을 되먹임으로 묶는 것이 차별점임

## 목표와 판정 조건

- 〔표 n〕의 〔개수〕 축을 모두 달성해야 하며 〔하나라도 못 채운 경우〕 최종 목표 미달로 판정함
- 착수 〔단계〕는 〔확보된 것〕이 확보된 상태이고 종료 〔단계〕는 〔실적〕과 〔증빙〕으로 판정함
- 〔현재 수준〕이 〔기준〕 〔수치 단위〕를 웃돌므로 〔지표〕 목표를 〔수치 단위〕 이내로 둠

## 위험과 대체 경로

- 〔실패 상황〕이 최대 위험이며 〔시점〕을 〔판단 대상〕 판단 시점으로 지정함
- 〔시점〕 점검에서 〔지표〕 〔수치 단위〕 미달이면 〔대응 1〕을 보강하고 〔다른 실패〕 시 〔대응 2〕를 바꿈
- 최종 목표의 판정 기준은 낮추지 않으며 〔앞 단계〕에서만 〔조정 대상〕을 조정해 〔범위〕를 바꿈

## 산출식

- 〔총량 수치 단위〕는 〔연차〕 〔수치 단위〕와 〔연차〕 〔설비〕 〔대수〕 병렬 각 〔수치 단위〕의 합이며 대당 가동률 〔수치 %〕임
- 총 〔금액〕 중 〔재원〕 〔금액〕을 1단계 〔금액〕·2단계 〔금액〕으로 나눔
- 〔효과 대상〕 상한은 〔수치 단위〕와 〔수치 단위〕의 격차임(〔출처〕, 〔연도〕 기준)

## 역할 분담

- 〔주관기관〕이 〔작업 나열〕을 총괄하고 〔참여기관 1〕은 〔작업〕, 〔참여기관 2〕는 〔작업〕을 수행함
