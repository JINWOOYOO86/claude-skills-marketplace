# 연구주제·키워드 등록양식

**이 폴더의 양식이 이 스킬의 유일한 설정 파일이다.** 관심사가 바뀌면 여기서 만든
`profile.md` 한 파일만 고치면 된다 — SKILL.md·러너 스크립트·스케줄은 건드릴 필요가 없다.

| 파일 | 무엇 |
|------|------|
| `profile.template.md` | 빈 등록양식. `{{ }}` 를 채워 쓴다 |
| `profile.example.md` | 채워진 예시 1편(**가상 인물**). **어느 정도로 구체적이어야 하는지**의 기준 |

## ⚠️ 채운 프로파일은 저장소에 올리지 않는다

연구축 서술 + 규모·기간 하한 + 탐색 범위의 **조합은 그 자체로 개인과 소속을 좁히는 준식별 정보**이고,
어떤 규모의 과제를 노리는지 드러나므로 경쟁 정보이기도 하다. 기관명을 `○○`로 가려도 마찬가지다 —
좁은 분야에서는 연구축 4개의 조합만으로 사람이 특정된다.

- 채운 `profile.md` 는 **루틴 폴더에만** 두고 저장소·공유 폴더 밖에 보관한다.
- 이 폴더의 `profile.example.md` 는 **지어낸 가상 연구자**여야 한다. 실제 프로파일을
  "예시"로 바꿔 넣지 말 것 — 「가상의 예」라는 표기가 붙으면 검토자가 걸러낼 기회를 잃는다.

## 쓰는 법

```bash
# 1) 양식을 내 폴더로 복사한다 (루틴 폴더 또는 프로젝트의 _workspace/)
cp <플러그인>/assets/profile/profile.template.md ./profile.md

# 2) 편집기로 열어 {{ }} 를 채운다
# 3) 끝. 다음 실행부터 이 파일을 기준으로 판정한다
```

대화로 만들어도 된다 — 프로파일 없이 스킬을 부르면 항목을 하나씩 물어 이 양식대로 파일을 만들어 준다.
만들어진 뒤에는 **사용자가 직접 고치는 것이 정상 경로**다.

파일 이름과 위치는 자유다. 스킬은 다음 순서로 찾는다:
`profile.md` → `00_scout_profile.md` → 사용자가 대화에서 지정한 경로.

## 스킬이 이 파일을 다루는 규칙

- **사용자가 쓴 내용을 임의로 고치지 않는다.** 키워드 추가·제외어 변경 같은 편집은
  사용자가 요청했을 때만 하고, 무엇을 바꿨는지 보고한다.
- 스킬이 자동으로 갱신하는 곳은 맨 아래 **「실행 이력」 표 하나뿐**이다
  (최종 탐색 시각·다음 회차 확인 사항). 이게 증분 탐색의 기준점이 된다.
- 양식에 없는 항목을 임의로 추가해도 된다. 스킬은 모르는 항목을 무시하지 않고
  **판정 참고자료로 함께 읽는다** — "이런 과제는 피하고 싶다" 같은 자유 서술도 유효하다.

## 왜 키워드가 아니라 서술문인가

관련성 판정은 키워드 문자열 매칭이 아니라 **의미 대조**다. 키워드는 검색어 생성과 1차 훑기에만 쓰이고,
직접관련/간접관련/무관 등급은 「내 연구주제」 서술문과 RFP 원문을 견줘서 나온다.

그래서 이 양식에서 **가장 중요한 칸은 맨 위 3~5줄**이다. 키워드를 20개 넣는 것보다
연구축을 (1)(2)(3)으로 또렷하게 쓰는 편이 판정 품질을 크게 올린다.
